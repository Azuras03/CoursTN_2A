# Humeurs de chenilles

Chaque chemille a un cadre de référence, donc appliquer filtres par rapport à leur observation.

**Doute positif** : Essayer de comprendre pourquoi l'autre pourrait avoir raison avant de dire qu'il a tort

La carte n'est pas le territoire : La représentation n'est pas une personne
Ceci n'est pas une pipe

Le réel != la réalité != les représentations != le symbolique

- Réel : tout ce qui nous environne (on l'a en commun)
- La réalité : Ce que chacun perçoit du réel par ses sens
- Les représentations : Ce que je vais enregistrer par rapport à la réalité (une expérience particulière). Une bande de données où je vais puiser. Cela est radicalement différent d'une personne à une autre. Par exemple avec les chats, moi j'imagine mon chat
- Le symbolique : Notre interprétation

Tenir compte du feedback pour comprendre les perceptions des autres.

Le mot est fondamental, mais représente un petit pourcentage dans le message (7%).

Proverbe : Celui qui parle sème, celui qui écoute sème et récolte à la fois.

- Observations : Mon voisin a acheté une nouvelle voiture
- Inférence : Mon voisin gagne bien sa vie

Différence entre ce qu'on pense et ce qu'on dit

La congruence : Un accord idéal entre ce que je pense, ce que je ressens et la manière dont je vais m'exprimer. Aucune ambiguité pour les autres du coup.
