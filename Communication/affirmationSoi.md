# OSER

- Négocier : Pour évoluer
- Poser ses limites : Savoir dire non
- Prendre des risques / initiatives / décisions
- Être fidèle à soi-même (congruent)
- Se remettre en question
- Critiquer
- Reconnaitre ses torts 

## Pôles

- OK : Oser
- KO : Pas oser

Basé sur les croyances

En fonction de :
- Ma position 
- Celle des autres

| Dominant (+,-)  | Coopératif (+,+) |
| --------------- | ---------------- |
| Nihiliste (-,-) | Dominé (-,+)     |

## S'affirmer

4 manières d'être
- Fuir
- Attaquer
- Manipulation
- Assertivité

Les trois premiers comportements coûtent cher, le dernier peut être intéressant à tester :D

## Lecture dialogue patron-secrétaire

Patron :
- Reproche, critique indirecte exagérée, message à risque
  - Dans le but de faire culpabiliser l'autre
- Menace

Secrétaire : 
- "Reconnaissance" de torts
  - Auto-dévalorisation

Révélation sur soi : Dire ce qu'on ressent

Il faudrait que la secrétaire repasse sur le pôle+, quand le moment est le bon, faire une révélation sur soi ou dire ce qui lui a gêné.

**Référence** : Fais-toi confiance - I FILLIOSA
